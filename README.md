# 🌻 TaskWarm – MERN Task Manager

A warm, aesthetic full-stack task management app built with the MERN stack.

## 📁 Project Structure
TASKMANAGER/
├── Backend/    → Node.js + Express + MongoDB API
└── Frontend/   → React.js UI

## 🛠 Tech Stack
- **Frontend:** React.js, React Router v6, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Auth:** JWT + bcryptjs

## 🚀 Quick Start

### 1. Backend
cd Backend
npm install
cp .env.example .env
npm run dev

### 2. Frontend
cd Frontend
npm install
npm start

Open http://localhost:3000
